# Spec2Maude

Spec2Maude translates [SpecTec](https://github.com/Wasm-DSL/spectec) language
specifications into executable [Maude](https://maude.cs.illinois.edu/) semantics.
It connects structured language definitions with rewriting logic, making the
resulting semantics available for program execution, state-space exploration,
and model checking.

The project applies this approach to WebAssembly. Its SpecTec specification
provides the syntax, auxiliary functions, and execution rules from which
Spec2Maude generates the Maude semantics.

## Translation approach

Spec2Maude uses the SpecTec parser and elaborator to obtain an intermediate-
language AST, then recursively translates that AST into Maude declarations,
equations, and rewrite rules.

```text
SpecTec specification
        |
        v
SpecTec parser and elaborator
        |
        v
SpecTec IL AST
        |
        v
Recursive IL-to-Maude translation
        |
        v
Generated Maude semantics + backend support
```

The OCaml implementation is organized by AST family. Each translation follows
the corresponding source construct, keeping the relationship between the
specification and generated code visible in the implementation.

This baseline removes heating/cooling and dedicated sort/proper hints from main.
Other translation behavior and optimizations remain as in main. Source hints
still select builtin, inverse, and explicit backend interfaces. See
[baseline scope](docs/BASELINE.md) for the removed hints and runtime adjustments.

## Working with WebAssembly

The `wasm2maude` frontend translates WebAssembly modules and test scripts into
Maude program configurations. These configurations run with the semantics
generated by `spec2maude`.

Together, the two frontends connect a language specification, concrete programs,
and Maude's execution and analysis tools. The same generated semantics can be
used to evaluate a program, explore reachable configurations, or check temporal
properties in a composed model.

## Project structure

| Path | Role |
| --- | --- |
| [`spectec/`](spectec/) | SpecTec frontend, IL definitions, and WebAssembly specification |
| [`translator/`](translator/) | Recursive SpecTec IL-to-Maude translator |
| [`translator/maude/`](translator/maude/) | Maude intermediate representation and renderer |
| [`translator/backend/`](translator/backend/) | Common representations, builtins, and relation implementations |
| [`translator/generated/`](translator/generated/) | Generated Maude declarations and semantics |
| [`wasm2maude/`](wasm2maude/) | WebAssembly program encoding and execution drivers |
| [`bin/`](bin/) | Command-line entry points |
| [`test/`](test/) | Translation and execution test entry points |
| [`benchmarks/wasm-spec/`](benchmarks/wasm-spec/) | Official WebAssembly core test suite |
